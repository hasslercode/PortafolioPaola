# Archived blog guides

These MDX files are not published. The site registry only loads the 20 guides in `src/content/blog-catalog.ts`. Each archived slug redirects with a single permanent hop (see `BLOG_REDIRECTS` in that file).

Do not move a file back into `content/blog/es` or `content/blog/en` unless it is also added to `KEPT_BLOG_SLUGS` and its redirect is removed.
