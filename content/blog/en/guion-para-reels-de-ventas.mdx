## Short answer

A **sales Reels script** turns scroll into conversation. It does not start with “we are leaders in…”. It starts with tension: a real problem, measurable promise or proof that forces viewers to stay. Then demo, social proof and CTA to WhatsApp, DM or store.

For script + editing + publishing, see [content production](/en/services/content-production) and [pricing](/en/pricing).

## Why script precedes editing

Editing multiplies a clear message; it does not invent one. [How to edit retaining Reels](/en/blog/como-editar-reels-que-retienen) assumes you know what to say in each second block.

Retail brands in Colombia — Coca-Cola, Starbucks, H&M, TOTTO, Cine Colombia — use short scripts with clear function in campaigns that together exceeded **+1.3M organic views** in documented contexts. Lesson for SMEs: one strong script per piece, repeated with variations.

## PAS structure in 30 seconds

**P — Problem:** uncomfortable question or situation (0–5 s).

**A — Agitate:** cost of not solving (5–12 s).

**S — Solution:** product/service + demo (12–22 s).

**Proof:** testimonial, data, before/after (22–27 s).

**CTA:** single action (27–30 s).

## 30s template (physical product)

```
[0-3s] HOOK: "Does your skin react to every 'natural' cream you buy?"
[3-10s] PROBLEM: "Most hide fragrance..."
[10-20s] SOLUTION: Show texture, ingredients, application
[20-25s] PROOF: "María in Medellín reduced irritation in 2 weeks"
[25-30s] CTA: "Comment PIEL and I'll send list via WhatsApp"
```

Use real names — do not invent testimonials.

## 45s template (B2B service)

```
[0-3s] HOOK: "Your community manager posts... but do they sell?"
[3-15s] EDUCATION: 2 signs of content without strategy
[15-30s] OFFER: What your service includes in one sentence
[30-40s] PROOF: Client case or documented process
[40-45s] CTA: "Book diagnosis — link in bio"
```

Full list in [hooks first 3 seconds TikTok](/en/blog/hooks-primeros-3-segundos-tiktok). For sales, prioritize direct pain questions, “stop doing X if you want Y”, specific numbers and immediate demo.

## Social proof without lying

Use real testimonials, screenshots with permission, typical results with honest disclaimers. Do not cite invented metrics.

## CTA for Colombia

| CTA | When to use |
|---|---|
| WhatsApp | Services, consultations |
| Comment keyword | Lead magnet, lists |
| Link bio | Ecommerce, booking |
| Instagram DM | Visual products |
| Save | Education before sale |

One CTA per video.

## Script vs improvisation

**Improvise** if you are expert and concise. **Script** if you batch record, delegate editing or need brand consistency.

Hybrid: bullets per block + one free take + pick best in edit.

## Monthly script batch

Week 1: four sales angles (objection, demo, comparison, real urgency).

Week 2: write 30s bullets each.

Week 3: batch record — [phone recording](/en/blog/grabacion-profesional-con-celular).

Week 4: edit, caption, publish.

## Objection Reels

One Reel per frequent objection: price, “won't work for me”, trust.

## Format and script

Write for [9:16](/en/blog/formato-9-16-guia-emprendedores): one idea per screen. [Captions](/en/blog/subtitulos-en-reels-mejores-practicas) repeat CTA and promise.

## Sales script mistakes

1. Logo or long bio at start
2. Three offers in one video
3. Weak CTA (“follow us”)
4. Vague promise
5. No concrete proof
6. 90s script without retention
7. Aggressive sales tone without empathy

## Editing that reinforces sale

Cut on each PAS block change. On-screen text with price/offer if applicable. Music low, voice forward. [Licensed music](/en/blog/musica-libre-de-derechos-reels-colombia).

Premium adds motion on CTA: [basic vs premium](/en/blog/diferencia-entre-edicion-basica-y-premium).

## Lighting and credibility

Well-lit face signals trust in personal sale. [Home lighting](/en/blog/iluminacion-para-videos-en-casa).

## Value vs sale calendar

80/20 rule: mostly value/education, minority direct sale. Sales script works better when audience already knows you.

## AIDA framework for Reels

**Attention:** hook 0–3s. **Interest:** problem 3–12s. **Desire:** demo + emotional benefit 12–25s. **Action:** single CTA 25–30s. One strong idea per visual block.

## Funnel stage scripts

Top funnel: myths, trends, light education — soft CTA (follow, save). Mid funnel: comparisons, cases — consultation CTA. Bottom funnel: offer, real urgency, dense proof — WhatsApp/purchase CTA.

## WhatsApp Business CTA Colombia

"Write us on WhatsApp" works with comment keyword + fast manual reply. Script must say what person receives ("I'll send PDF catalog", "we book 15 min").

## Teleprompter setup

Apps: PromptSmart, Teleprompter Premium, or tablet with Google Docs. Slow scroll, large font, practice 3 times before batch.
